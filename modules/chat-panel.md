## 模块基线与确认状态

- **默认与状态示例**：工具默认收起；展开、审批及单/多工具组合是相关状态示例。参考中的编号仅定位，不代表执行顺序。需审批时沿用当前 PRD 的授权逻辑，未授权不执行；取消与执行失败区别表达。
- **对象归属**：工具记录和结果归属对应调用；摘要与 Interrupted 归属助手回合。Stopped 是独立系统事件。Resend 按原请求生成新的响应，保留原中断回复与工具记录（用户已确认）。
- **引用与 Thread**：单条引用指向来源消息；Thread 是完整来源会话的实时投影。展开/收起与纳入上下文独立。单条失效只影响该条跳转。Quoted from 表示跨 Creation 放入的完整会话，保留原 Home（用户已确认）。产品流转仍对照本次适用 PRD，不能从卡片外观推断新建/移动/复制规则。
- **两类状态提示**：标题旁徽标表达当前会话状态，黄色为等待批准/回答，红色为工具失败。顶部入口与 Menu 彩点汇总其他筛选中的当前提示状态；共享旁注 `9809:158055` 的本轮设计判断为黄色 > 红色 > 完成且未读，只显最高优先级一个点；历史失败保留记录但不永久累计红点。此排序不是 PRD 原文，后续明确需求变更时同步两处入口。
- **工具过程范围**：2026-10-29 用户已撤下 Tool Use 的 B1/B2 分支方案；开发采用当前基础工具状态和完整聊天示例，不再将这两种展示作为备用方案或待确认事项。

## 新 UI 如何延续现有模块

其他页面承载 Chat Panel 时，在交付画面内复用所需的会话标题、消息回合、工具状态和输入区。宿主的外层布局可随场景变化，局部调整按[模块复用规则](README.md#如何使用)记录。

按阅读正文、标题、导航/元信息、工具控件分别选择密度与字阶；对照相邻状态的对齐、间距、图标、留白与文字层级。库中已有组件与图标优先复用，已有项目组件 API 保持一致。落在尺度内的值映射现有 token；设计指定局部差异逐项记来源，不吸附到最近档位、不改全局默认。

- 局部量测与字重映射仅引用 [design.md §7.8](../design.md#78-聊天侧栏局部参考medeo-桌面切片)：正文 14/20、实际字重 500 与导出 token 600 的差异，气泡上下 6px 等均为有来源的局部参考；不复制成另一套数值表。
- 通用角色与密度见 §2.1，颜色/状态与间距/圆角见 §4，文字见 §5，组件/图标见 §6，浮层见 §8，响应式见 §12。桌面切片不能证明移动端、实际命中区或键盘行为，相关任务仍需验证。
- 标注中的示例计数、时间、拼写及 prompt 内容仍有一致性备注（`9809:157060`），不直接当最终产品文案。
