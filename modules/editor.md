## 功能基线与参考使用

视觉对齐保持原有 relation、关联选择与拖动行为，以及自上而下 `caption → speech → video → BGM`。不因参考分支布局或重排代码改变关系功能与四轨顺序；显示关联线时同时核对有无 caption / speech、隐藏轨及选中 / 拖动态。

## 配音稿与工具栏

- 阅读与编辑使用一致的文字起点、字阶、行高、换行宽度与行内留白；进入或退出编辑时文字不跳动。辅助工具的显隐不能推挤正文或延迟结束编辑。
- 工具栏按钮与同角色的相邻按钮对齐，分别核对 icon 可视尺寸、按钮容器与实际命中区，不将三者当同一尺寸。
- 音素按钮不可用时在整钮根层再乘 `0.4`，包含图标和文字；内层原有透明度保留，因此不表示每个最终像素的 alpha 都为 `0.4`。不可用时箭头光标，可用时手形；核对 tooltip 与实际操作是否一致。
- Voiceover 工具显隐保留布局，不推挤正文；时间戳、字数和辅助按钮文字按角色对齐字阶与左起点。
- 行内 Apply to voice 使用 6px 圆角和同色文字、图标；不可用时在整钮根层再乘 `0.4`，与弹窗内的 Apply 按钮分别核对。
- Apply 语音操作需比相邻辅助操作更醒目，按当前可用、不可用和 loading 状态分别核对主次；不能仅增强一个内层图标而留下整钮层级不一致。

## 播放器与四轨时间轴

| 项目 | 本轮最终局部基线 |
| --- | --- |
| 播放器时间 | `11px`，Medeo `--Label-Small-Size`；Geist Mono + `ss09`，显示百分之一秒，保持与邻近控件垂直居中；总时长同色降透明度，斜杠两侧各留 2px margin |
| 播放器进度 | 底轨黑色 `0.2`，缓冲层白色 `0.2`；两层叠加在媒体画面上，不能只报告其中一层 |
| 四轨间距 | `6px`；按 `TIMELINE_TRACK_GAP` 核对，不推广为通用 Space 档 |
| 时间轴默认高度 | `297px`；是默认初始值，不能覆盖用户拖动后的高度 |
| 轨道操作 icon hover 底 | `20 × 20px`；实际命中区另行核对 |
| 轨道类型 icon | 透明度 `0.4`；不要顺带把操作 icon 也降到同一值 |
| 禁用轨内容 | 完整内容先合成，再在根层乘 `0.4`，保留内部固有 alpha；不得靠子绘制覆盖 alpha 恢复为不透明 |
| 轨道标题遮罩 | 覆盖静态内容和 hover / 选中 / 拖动交互层，不能只遮住底层 clip |
| 关系线 | 下端 video 中心至上端最高可见相关轨中心；从下到上 alpha `1 → 0`，沿用主题关系线 token；只对有关系的可见轨计算端点 |

关系线保持原 relation 的来源与作用范围；不要用另一份参考实现取代关系逻辑。数字、状态与功能基线需一起验证。

## 音频包络与加载

- fade 控制点内外圆同心，圆形使用 `corner-shape: round`；填充、描边及高亮采用语义 token（当前实现为 `Schemes/Primary`、`Surface/Surface Bright`、`Surface/On Surface Variant`），深浅主题都核对。
- 画幅元数据未知时显示中性的加载骨架，不猜 `16:9` 或其他内容比例；数据到达后再按真实比例布局。
