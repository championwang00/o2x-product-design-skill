# CommandBox / RTE 模块

适用范围：Medeo 命令框、SdkRichInput、Recipe、预置文本槽、segment、顶部 chip 与附件卡。关联状态在本模块独立设计，不能套用 Createspace 的单条状态优先级。

## 来源与核对状态

最后核对：2026-11-02。来源：本轮 CommandBox / RTE 用户走查结论、宿主 segment README、关闭链路与 recipeFreeText 浏览器测试断言、本地 SDK 源码复核（含 focusNotch 的 20/2 参数）；未读取新的 Figma 参考，不构成 Figma 库或 token 修改。以下明确区分设计原则、局部参数、SDK 能力与待确认事项；实现反馈不等于视觉验收。

## 已确认原则

- 自身 hover 用背景表达；整段选中用 1px 紫色外框与 1px 焦点线。文本拖选与整段选中是不同状态，拖选使用 12% 选区。
- 自身状态、父子从属关系、同一对象的其他实例分别建模。父子不等于同对象分身；关联副态独立保留，不能因为自身 hover 改用背景就消失，也不能沿用“多个状态只保留最强一条”来抹掉关联。
- 预置槽的叉清空槽内容并保留槽；放入的 segment 的叉删除该 segment。不能把两者统一成删除容器，也不能把叉的清空规则直接套到所有键盘删除路径。
- 关闭配方与键盘删除整段 Recipe 按两个入口分别验证：当前产品顶部关闭会经 recipe.unset → removeRecipeBlock 删除配方及框内内容；键盘删除已选 Recipe 也删除选中内容。两者都移除顶部 chip、保留框外正文；关闭不是仅解除标记、保留框内文字。删除后在原位置新建的结果与完整键盘路径仍需产品验收。
- CommandBox 菜单用快速淡入，不缩放；这是模块例外，不改其他浮层动效。
- Recipe 封面底叠低透明度中性色以维持封面色调，不能用强遮罩替换原色。焦点线与相邻轮廓交叠时只在交叠边局部让位，不整体缩小外框。

## 当前局部参数

这些参数只属于本模块，不提升为全局 token 或其他模块默认值。

| 部位 | 当前值与状态 |
| --- | --- |
| Recipe 封面底叠色 | 浅色主题黑色 2%；深色主题白色 2% |
| 槽与 Call 主壳 hover | 浅色 6%；深色 7%，不画 hover 边框；不是静止背景值 |
| Call 内部属性 / ⋯ | hover 与键盘聚焦使用 8% 中性背景，与主壳分开 |
| 同对象关联副态 | 当前顶部 chip / 附件卡：hover 1px Primary 25%；selected 1px Primary 50%。编辑器内部尚未绘制 |
| 普通插入光标 | 1px 宽、18px 高，行内居中 |
| 整段 selected 焦点线 | 1px 宽；当前本地 SDK 参数下中心线高 16px（selectionHeight 20 − 上下各 gap 2），与普通 18px 光标不同；这是当前实现值，不提升为全局规范 |
| 焦点交叠边 | 上下各让位 2px，端点为圆端 |
| 白色外框与 Recipe | Recipe 背景距白框上边、左边及铺满行时的右边各 14px；白框圆角 20px，Recipe 圆角 6px |
| 菜单淡入 | 当前修复中的实现值 60ms；尚不作为验收定值或全局时长规范 |

## SDK 当前限制

当前产品仅在顶部 chip 与附件卡实际绘制关联副态；编辑器内部存在关联状态数据，但 SDK 尚未绘制对应副态。这是能力限制，不能写成“编辑器内部不需要关联”的设计原则，也不能据此声称关联视觉已完整实现。

## 待确认

- 父子关联的虚线表达、层次关系与深层数值曲线尚待设计确认；不把旧的“父子完全不展示”作为本模块默认，也不自行指定虚线参数。
- 同对象关联与父子关系同时命中时的完整视觉组合、顶部 chip 点击后的定位 / 选中行为，需要当前证据核对；旧示例不作为定稿。
- 菜单最终时长与编辑器内副态绘制完成后的组合状态仍需真实预览验证。

## 演示与产品验收边界

HTML 是状态与排版样本：显式按钮重放 hover、整段 selected、文字选区、删除和新建结果；不模拟字符编辑或完整键盘状态机。DOM / SVG 连续皮、原生拖选高度和示例量测不能作为 SDK 几何通过的证据。

真实 SDK / 产品应另验左右双向进入与退出、从内部撞边界先整段选中、Shift 扩选、逐字删除、IME、复制粘贴与撤销；同时验证关闭与删除、预置槽清空、独立对象删除。上传、生成、发送及未接业务的菜单项只可称外观样本。当前本地 SDK 能力、已发布包与产品线上状态需分别说明，未发布或失败的检查不能写成已落地。

## 验收入口

核对自身 hover、整段选中、文本拖选、同对象副态和父子关系的组合；分别检查顶部 chip、附件卡及编辑器内部，报告 SDK 缺口。核对槽清空 / segment 删除、明暗主题底叠色、焦点线局部让位和菜单快速淡入。
