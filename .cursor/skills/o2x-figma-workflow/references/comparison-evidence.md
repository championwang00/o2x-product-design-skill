# 比较与标注证据

比较同角色、同状态的有效节点；分列字体/行高、容器/内距、组内/组间距、图标图形/设计容器/实际命中区，以及内容范围与折叠状态。记录保留项和变化项；不同宽度、换行或条目数不能直接解释为密度变化。截图不证明绑定、实际命中区或交互行为。

完整内容与摘要预览分开评估：记录业务对象、展示范围、折叠与截断；静态图不能证明来源完整性或触发方式。评色时记录透明度和预期承载表面，在已确认表面合成检查图并保留原图；不要把透明图查看背景误当产品底色。

按当前确认语义逐组逐边检查默认/备用/并列/来源及实际两端；映射每条用户反馈到对象和复核结果。变量绑定、几何边界与截图可读只是独立证据，不替代关系核验。
